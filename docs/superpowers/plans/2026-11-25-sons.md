# Sons des combats — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** sons réalistes CC0 joués au moment exact des animations du combat, bouton son actif.

**Architecture:** le SWF de jeu appelle `window.mtSfx(kind, detail, x)` depuis le code d'affichage ; `player.js` joue les sons par Web Audio (panoramique, variations, limiteur, anti-bouillie, silence en saut/pause).

**Tech Stack:** JPEXS FFDec + JDK portables (`tools/bin/`), helpers AS3/P-code (`tools/oracle/instrument/patch-msg.as`, `build.ps1 -Play`), Ruffle, Web Audio, Playwright, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-25-sons-design.md`. Sons candidats : `scratchpad/work/sons/` (raw/meta.json = licences, out/ = traités, planche-sons.html = écoute ; style « réaliste » = fichiers `*_r*.mp3`).

## Global Constraints

- Trace SWF inchangé `a4afe044c3707993f7d49c7afe4fc6319a8c1012fd3e1fd563cd2b6eb9c1b08c` ; play SWF reproductible (deux dossiers → même SHA), `.sha256`, copie servie, `?v=14`.
- `mtSfx` n'est appelé que depuis le code d'affichage : jamais dans l'état 0, la simulation (`mtSimFrame`/`resolve`), ni pendant le rejeu caché d'un saut (`mtGoto`). Historique identique aux goldens (tests existants).
- Sons : uniquement CC0, style réaliste ; crédits (auteur, lien Freesound) dans le README.
- Textes en français ; commentaires en anglais, sobres.

## Review Focus

- Saut (avant/arrière, frise, journal) : aucun son pendant le rejeu, puis sons normaux à la reprise.
- Pause native ouverte : aucun son ; reprise : sons.
- Vitesse ×32 : pas de saturation ni de mur de bruit (plafond de voix, fenêtre par type).
- Onglet caché / dialogue ouvert : silence.
- Premier chargement sans geste utilisateur : pas d'erreur console (AudioContext suspendu), le son démarre au premier geste.
