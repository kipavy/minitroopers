# Interface adaptative (téléphone et tablette) — plan d'exécution

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** rendre toutes les pages du site jouables de 320 à 979 px de large, en gardant l'identité MiniTroopers, sans changer un pixel au-dessus de 980 px.

**Architecture :**
- Les règles CSS vont toutes dans `apps/server/public/css/extras.css` :
  - sous `@media (max-width: 979px)` pour le téléphone ;
  - sous `@media (min-width: 600px) and (max-width: 979px)` pour les deux colonnes de la tablette.
- Elles sont toutes préfixées par `body.mtm`. `layout()` ajoute cette classe à toute page qui porte la balise `viewport`, ce qui est désormais le cas de toutes les pages.
- Le cadre d'origine est reconstruit avec `border-image`, à partir de ses images d'une ligne de haut.
- Un outil de captures par CDP (Brave ou Chrome sans interface, sans dépendance) fournit les vérifications que les tests Node ne peuvent pas faire :
  - le débordement horizontal ;
  - l'identité au pixel près sur ordinateur ;
  - les captures à montrer à Killian.

**Tech Stack:** Node 24 (TypeScript natif), Hono SSR, CSS, Ruffle, `node:test`.

**Spec :** `docs/superpowers/specs/2026-11-25-mobile-design.md`. La lire en entier avant de commencer.

## Global Constraints
